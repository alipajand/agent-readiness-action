# Security findings

Findings from the release review of the integrations (2026-10-12), updated by the reconciliation
review of this pull request and agent-context-doctor#74 on the same day, and again after #74 was
merged and `vendor/agent-context-doctor` moved to its merge commit `034a74c`. Sources: two independent
reviews (a rule-based security review of the diff and an adversarial review that exercised the
built artifacts) plus issues found while building and testing. Each finding has a regression test
unless marked otherwise.

## What masking guarantees

Guaranteed (tested, with the engine at `034a74c`):

- Any value matching the doctor's credential patterns (AWS, GitHub, Anthropic, OpenAI, Google,
  Stripe, Slack, npm, and `password=`/`api_key:`-style assignments of letters and digits) is
  masked in every issue's `message`, `recommendation`, and `evidence` by the doctor itself, and
  also in `id` by the integrations runtime. That covers the skill's JSON and Markdown, MCP
  summaries, pages, and `include_raw`, and the action's log, job summary, and outputs (the action
  prints file, line, and message). The first four characters stay visible.
- A value configured under a credential-like key in an agent config file's `env` or `headers` is
  masked as a whole (first four characters visible) in every finding of that file that quotes its
  line, even when it matches no pattern or a pattern matches only part of it.

Best effort or not masked:

- Detection is pattern-based. A credential in an unknown format, or a configured credential quoted
  on another line or in another file, is shown as written.
- File paths (`file`, report `files[].path`, readiness check `files`) and readiness messages that
  name paths or `package.json` script names are reported as they are, so the file can be found.
  The readiness engine never quotes file contents or script commands.
- Values shorter than five characters stay visible (the mask keeps four characters). A private key
  is reported by its `-----BEGIN … PRIVATE KEY-----` line, which is shown as is; key material on the
  following lines matches no pattern, so it is shown as written if another finding quotes one of
  those lines.

## Accepted limitations

- **Node's permission model is a second layer, not the boundary.** A granted read can follow a
  symlink out of the granted directory, and `lstat('<granted>/..')` was observed to succeed on
  Node 24.11. Containment of reads rests on the path checks in the runtime and the engines.
- **Residual race on the local filesystem.** After the worker's canonical check, the engines walk
  the tree by path. Someone who can swap directories inside the audited tree during the audit
  already has local write access to it.
- **`.arkrc` is ignored.** Results can differ from `ark audit` for a repository whose `.arkrc` is
  invalid (the CLI exits; the runtime scores). Documented in `SKILL-USAGE.md`.
- **CLI usage errors are text even with `--format json`.** Exit code `2` distinguishes them.

- Cursor loading the plugin.
- Any Windows run.
